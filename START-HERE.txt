Synergy Guild Dashboard

To preview locally:
1. Double-click run-local.bat (requires Python on Windows).
2. Visit http://localhost:8000.

To update the data everyone sees on the hosted page:
1. Export the roster and guild activity log in Neverwinter.
2. Double-click update-dashboard.bat. It selects the newest GuildMembersListLogs*.csv and copies it to data\roster.csv. It copies GuildActivityLogs.csv to data\activity.csv, verifies both copies, and rebuilds data\snapshot.json.
3. Commit and push data\snapshot.json to the GitHub Pages branch.

The copied CSVs use stable filenames and are ignored by Git. Only the sanitized snapshot is published.
