Synergy Guild Dashboard

To preview locally:
1. Double-click run-local.bat (requires Python on Windows).
2. Visit http://localhost:8000

To update the data everyone sees on the hosted page:
1. Replace data/roster.csv and data/activity.csv with the latest exports.
2. Double-click update-dashboard.bat to regenerate data/snapshot.json.
3. Commit and push data/snapshot.json to the GitHub Pages branch.

Raw CSVs stay local and are gitignored. Only the sanitized snapshot is published.
